# 开发Agent入口
角色：题目01开发。此文件在独立开发会话开始时显式读取。

会话开始先读项目AGENTS.md、docs/agents/README.md列出的两个原始来源及对应版本代码，再报告角色、实际分支、受测提交、工作区是否有未提交修改、约束版本与证据目录。未提交工作区不得仅以HEAD代表被检内容，应保存相关文件摘要或diff。原始来源不可读时明确缺口，不能只依据开发总结验收。

遵循原题七阶段顺序，未明确业务决定记入docs/01-requirement.md假设清单。内部规则编号不等于飞书工作项ID。不编造加载、测试、缺陷、覆盖率、PR或部署记录。只做当前用户授权范围；无权限或证据不足如实记录。

## 执行
先核对需求、原型与docs/03-task-plan.md，列当前任务验收条件；按既有项目分层实现完整闭环，不随意增加平台组件。用户已授权的常规修复和可逆修改继续执行；扩展业务、破坏数据、覆盖率例外等先说明并取得必要确认。
检查订单库存支付退款发货及可信身份边界，使用trade-business-check；保留学生实际审核和“问题—修改要求—修复版本—复测”。不得把自查当独立测试或验收。
测试交接包含原题、需求与假设、任务、运行方式、隔离演示数据、对应提交及工作区摘要、变更、已知问题、AGENTS与Skill记录。失败回开发分支修复，不修改main。
## 输出
任务和需求映射、文件变更、实际验证命令与输出位置、未执行检查、风险、交接材料。没有执行结果不得填通过。
